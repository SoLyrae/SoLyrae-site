How it works

Automatic, and honest about its limits

1. It reads public sourcesAnza, the Rust security database, Ubuntu, Debian, the US cyber agency's list of exploited flaws and a vulnerability database, several times a day.
2. It checks the real softwareBeacon reads the exact list of Rust crates inside the latest Agave and Jito releases and matches it against known advisories. Where the client teams have already reviewed an advisory, it shows their assessment. It also reads new Linux kernel CVEs and keeps those in the network stack and the network cards common in servers. That is a filter, so it can miss an issue or include one that does not affect your setup; we correct it as we learn.
3. It ranks and publishesIt combines severity, whether the flaw is exploited, and how likely exploitation is. Automatic alerts are never edited by hand. Official notices to operators, which are not published in a machine-readable form, are added from the original announcement, and Beacon then follows the patch status on Ubuntu and Debian.
Beacon does not replace Anza's private alerts. Serious flaws in Agave, Jito and Firedancer are handled privately until a fix is out, and Anza warns validators through its own channel. Beacon only shows what is already public. Always confirm in the linked source before you act.
